# Legacy v1 experiment registry

This registry is frozen on `charting-loop/registry-entry/v1`. Its source records live
under `registry/runs/`; `INDEX.json` and `EXPERIMENTS.md` are deterministic generated
views.

Do not submit v2 Candidate or neutral exogenous records here. New neutral task, study,
run, and score data belongs under `exogenous/` and is validated by
`tools/exogenous_registry.py`.

The legacy registry remains available to reproduce pilot v1 artifacts. Indexing does
not endorse a system, certify semantic correctness, establish authority, or support a
causal claim.
