# Exogenous-authority study design — template

The assigned condition is frozen before construction. Every condition uses the same
runner-owned visible interaction capture, actor identifiers, authority-event vocabulary,
candidate revision boundary, evaluator protocol, and publication/redaction rules. The
condition-specific script may vary only the authority input permitted after founding
provision.

This template is illustrative. A confirmatory study must pre-register allocation,
condition scripts, analysis unit, exclusion rules, and stopping rule.
