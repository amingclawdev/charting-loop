# Standardized-interactive authority condition — template

The founding user message provisions the task. During construction, the authority actor
may answer an explicit clarification request or issue an explicit reframe, redirect,
ratification, repeal, or delegation. The runner records the full visible exchange and
the derived authority event. Silence, praise, and assistant-authored text are never
treated as an authority act.

This file demonstrates how a condition is pinned. A real confirmatory study must replace
it with its pre-registered interaction script before the run.
