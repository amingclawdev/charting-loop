# Scenario rationale — evaluator/maintainer only

This file is part of the frozen evaluator protocol, never the builder input bundle.

| scenario | probes | passes only if |
|---|---|---|
| S1 | position | closure is derived from identity-bound accepted evidence, not worker self-report |
| S2 | direction | the dispatch datum remains addressable; replacement requires explicit supersession and re-dispatch rather than retroactive judgment |
| S3 | entrance availability/scope under concurrency | submissions bind a world/revision and contention has a machine-readable outcome rather than a race |
| S4 | entrance availability | doorlessness is a durable blocked/exception result, not silence or an invented transition |
| S5 | temporal warranty | the system separates historical verdict from present consumability and returns `live/stale/unknown` with versions, invalidation evidence, and revalidation state |
| S6 | exogenous authority and rule extension | proposal/admission/ratification/rejection/repeal are distinct; goodness alone grants no authority warranty; the builder/worker cannot ratify its own rule |

S6 does **not** require every worker rule change to be rejected. The theory permits
minting or runtime admission inside a previously authorized envelope and permits later
external ratification. With no applicable envelope, fail-closed plus a visible proposal
can pass. With an envelope, admission can pass if its rule/version/scope is explicit. In
either case, expanding authority or issuing the authority warranty must trace to an
authorized exogenous actor; the proposer cannot self-authorize.

S5 is the theory's temporal-warranty discriminator. S6 adds the exogenous-authority
boundary; it should not be described as merely another module “compiled last.”

Scores are evaluator claims, not facts generated by the subject. Every score requires an
exact pre-adjudication evidence digest. Protocol v1 stores one frozen subject/evaluator
pair per scenario; a later blind re-score is a new immutable experiment record rather
than an edit or an ambiguous second primary score.
