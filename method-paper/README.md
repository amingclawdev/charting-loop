# Method paper

`METHOD.md` is the sole normative method source. `SCOPE-DATUM.md`, `OUTLINE.md`,
`VERSIONS.json`, and `references.bib` record scope, navigation, version identity, and
bibliography; they do not add method requirements.

The service-plan example linked from `METHOD.md` is a completed, non-normative
engineering demo. It demonstrates one declared runtime-evidence path without unlocking
the method for operational adoption or establishing effectiveness. The Aming Claw
Contract-handoff paragraph is one non-normative projection; it is not a reference
architecture or evidence that the named system satisfies the method.

Within the method, Rule and Fact are input planes and Guide is the deterministic control
plane that returns one Entrance or typed refusal. Papers and packages are MethodRefs or
knowledge inputs; they are not Guide merely because they advise a builder.
