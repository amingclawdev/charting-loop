# Draft v2 Candidate schema

`templates/corridor/CORRIDOR.json` uses `charting-loop/candidate/v2`. It declares a
version-identifiable Candidate/revision, open/frozen state, semantic-closure digest,
cataloged MethodRef, Rule/Fact input planes, deterministic Guide control contract,
separate role definition and admitted-Fact-backed assignment, complete exact WorldRef, exactly
one tagged bounded semantic Entrance or typed refusal, implementation path/tree digest
with an explicit runner-owned Guide-contract carve-out, optional authority slot, empty
assurance slots, optional re-entry lineage, eligibility, and limits.

The Entrance binds one task reference, frozen Direction, and a unique legal-action set
whose canonical digest exactly joins one declared action-transition Rule carrying the
same digest. Its consumable instruction pins a facade ID/version/digest, nested interface
ID/version/digest/operation, the canonical digest of `argument_mode` plus `opaque_key`,
and a lookup-scope ID/version/digest at cardinality one. Its instruction contract puts
closed, single-result source selection on the runtime and forbids agent-side source
selection. A large file plus open grep/search/RAG instruction is semantically pull, not
a bounded Entrance. The Candidate WorldRef uses a strict HTTPS repository identity
(valid host/port; no credentials, query, fragment, whitespace/control, backslash, or
dangling port), project/run/generation identities, full base commit, environment digest,
RAW ledger prefix, admission receipt/root and Rule identity, projector schema/algorithm
identity, and derived-state digest. Timeline presence is not an admitted Fact. A branch
is never part of identity, and a WorldSpan may extend only the contiguous RAW prefix
under the same generation rules.

An Entrance Direction resolves exactly to one declared Direction-compilation Rule. A
typed refusal resolves its governing Rule and evaluated Guide input context. Candidate
`optional-evidence/` is pointer-only and excluded from semantic identity; raw optional
bytes live only under the exogenous run boundary.

The draft validator intentionally accepts only `template=true`,
`builder_eligible=false`, null assurance/re-entry slots, and null authority evidence
until a strict optional-evidence profile exists. It verifies exact object shapes,
catalog linkage, plane/control separation, role/Rule/object/Fact binding, declared Guide
determinism and tagged result cardinality, WorldRef bindings, recursively non-symlink
implementation trees, the action-set/transition-Rule digest join, pinned
facade/interface/arguments/scope declarations, bounded instruction lookup, and
open/frozen digest invariants. It does not index real v2 Candidate instances. These are
structural declarations: validation does not dereference those facade/interface/scope
digests, prove invocation, or prove closed runtime selection. Keyword screening is only
auxiliary. A real runtime profile will need a GuideReceipt and consume-time verifier.

Only a frozen Candidate revision is immutable and certifiable. Candidate semantic
identity includes the runner-owned Guide contract through the implementation-tree digest and excludes
later receipts, certificates, the exactly two Warranty kinds (EvidentialWarranty and
AuthorityWarranty), scores, and optional evidence. Appending
evidence therefore cannot change the Candidate being examined; changing frozen semantic
bytes creates a new revision.
