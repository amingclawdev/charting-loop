# Minimal v2 Candidate

This directory is a copyable open Candidate skeleton, not a runner envelope and not a
certificate. Its declared deterministic Guide returns exactly one tagged result: a
bounded, consumable semantic Entrance or typed refusal. Its Position binds a versioned
builder-role Rule separately from the authority/liveness-bearing holder assignment Fact,
which is also joined into the admitted Fact plane. A runner freezes the task, exact
complete WorldRef, including strict HTTPS repository identity, RAW ledger prefix,
admission, projector, and derived-state identities, a Rule-compiled Direction, a unique
allowed-action set canonically digested and joined to its declared action-transition
Rule, role/scope assignment, and Guide contract before the builder writes implementation
bytes. The contract pins facade/interface identities and operation, exact argument
digest, closed lookup-scope identity/digest, and cardinality one. It remains
runner-owned and read-only at `implementation/GUIDE-CONTRACT.md`; the final
implementation tree includes it when the runner freezes the semantic closure. Only that
frozen closure is immutable or certifiable.

The four record surfaces are intentionally orthogonal, and exactly two are Warranties:

- a traversal receipt records what ran across a same-generation contiguous-RAW-prefix
  WorldSpan;
- a path certificate judges the receipt against the frozen Entrance;
- an EvidentialWarranty is independently issued for a claim and has explicit liveness;
- an AuthorityWarranty independently binds the actor–role Assignment, Rule, scope, and
  authority source.

None is minted by this template. Authority logs and user–AI logs are optional and
live outside the Candidate under `exogenous/`; `optional-evidence/` may contain only a
local pointer/consent manifest, never raw log bytes, and is excluded from Candidate
identity. Log presence and format never gate validation or ordinary comparison.
Failed work opens a new revision. U → C completes only after that new
revision is frozen, freshly traversed, path-certified, and covered by a live scope-bound
EvidentialWarranty; its actor–role Assignment becomes consumable only when its
AuthorityWarranty is also live.

The validator checks declared structure, exact Rule joins for Direction, Position, and
the action-set digest, pinned instruction identities/digests, closed lookup
responsibility, and cardinality. Those declarations do not establish executable
facade/interface bytes, actual invocation, or deterministic runtime behavior; a future
real-Candidate profile must add a GuideReceipt and consume-time verifier.

Validate the non-indexable skeleton with:

```sh
python3 tools/corridor_registry.py validate-corridor templates/corridor --allow-template
```

Pilot v1 artifacts remain unchanged under `templates/legacy-corridor-v1/` and the
`registry/` contract remains explicitly v1.
